The final project includes its Gradle wrapper, Room schema, unit tests, instrumentation tests, sample CSV files, and dependency-free Java harnesses. Machine-specific SDK paths, build output, caches, and signing keys are excluded. Reproduction requires a compatible Android Studio/JDK and SDK installation.
